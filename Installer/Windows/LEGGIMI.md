# ChordPilot su Windows

La versione Windows (plug-in VST3 + app standalone, con supporto ASIO/WASAPI e MIDI automatico)
è la prossima fase del progetto e non è ancora inclusa in questo pacchetto.

Nel frattempo, con **Sideloadly per Windows** puoi installare la versione iPad sul tuo iPad
usando il file `iPad/ChordPilot-iPad-unsigned.ipa` (vedi `iPad/COME_INSTALLARE.md`).
